1. Problem Statement & Motivation

The Industry Problem

  • Reactive Tracking: Tools like Jira and Trello notify managers only after a deadline is breached.
  • Siloed Tools: Teams switch between Slack (chat), Trello (cards), and Google Meet, losing context.
  • Multi-Tenant Leaks: Cloud workspace platforms frequently risk cross-tenant data leakage if access controls are not verified on every SQL query.

Proposed Solution

  • Proactive AI Forecasting: Captures velocity snapshots at mid-sprint and calculates delay probability.
  • Integrated Real-Time Chat: Room-level WebSocket multicast with persist-then-broadcast guarantee.
  • Strict Multi-Tenant RBAC: Hard tenant isolation enforced at both the database and middleware layers.
Spoken Script: "Traditional project trackers are retrospective. Our innovation introduces proactive risk forecasting into standard Kanban boards so project managers receive early warnings before deadlines slip."

2. Project Objectives & System Scope

  • Multi-Tenancy & RBAC: Partition organizations, workspaces, and projects with roles (Admin, Manager, Member) and single-use cryptographic invitations.
  • Interactive Kanban Auditing: Drag-and-drop task lifecycle management with state transitions logged to task_status_history.
  • Machine Learning Microservice: FastAPI service returning delay probabilities ($p \ge 0.70 \rightarrow \text{High Risk}$) and continuous scores.
  • Generative AI Assistant: Meeting notes summarization and structured action item extraction via Gemini API.
  • Installable Android PWA: Progressive Web App with app-shell caching, standalone display mode, and touch-friendly controls.
Key Note: "All core modules were built in a 4-week solo development plan, with collaborative rich-text document editing explicitly deferred as future scope."

6. Database Design & Multi-Tenant Isolation

  • 16 Relational Tables: Enforce strict foreign key referential integrity in PostgreSQL 18.
  • Audit Trail: Every Kanban status transition appends an immutable row to task_status_history capturing old status, new status, progress, actor, and UTC timestamp.
  • Real Isolation Protection: Foreign keys keep data consistent, but true isolation is enforced by every query filtering by org_id and the requireRole middleware checking active membership before execution.
  • 10 Multi-Tenancy Tests: Proved that cross-tenant requests consistently return HTTP 403 Forbidden.
Viva Defense Q3: "Foreign keys keep data consistent, but they do NOT isolate tenants. True isolation is enforced by application-level query filtering on org_id and requireRole checking organization_members."

7. Real-Time Chat & AI Assistant

Socket.IO Chat Engine

  • Persist-Then-Broadcast: Messages are committed to PostgreSQL messages before emitting to room peers.
  • Reconnection Resilience: On drop/reconnect, clients fetch message history from database via REST API.

Generative AI Assistant

  • Summarizer: Transforms meeting discussions into 3-point executive summaries via Gemini API.
  • Action Extractor: Parses text into structured JSON tasks with assignees and estimated days.
  • Deterministic Fallback: Local NLP engine ensures offline reliability.

8. Installable Android Progressive Web App

  • App Shell Caching: Service Worker (sw.js) caches HTML, CSS, JS, and icons for offline resilience.
  • Zero API Caching: All /api/ calls bypass the cache to prevent data leakage between tenants.
  • Installed on Physical Android: Verified via Cloudflare Tunnel over HTTPS on a real Android phone in standalone display mode.
  • Touch-Friendly Controls: Each Kanban card features a 1-tap column selector alongside desktop drag-and-drop.
  • Zero Horizontal Overflow: Navigation automatically moves to an Android bottom bar at 390px mobile viewport.
