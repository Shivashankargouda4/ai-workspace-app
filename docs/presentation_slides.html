Slide 2: Project Abstract

1. What is this Project?

A single, complete website that brings together everything a software or college team needs: Task boards, Live Team Chat, Shared Documents, an In-Browser Code Editor, and Video Calling—all in one place under a single login.

2. The Main Problem It Solves

Today, teams waste valuable time switching between 5 separate tools (Slack for chat, Trello for tasks, Google Docs for notes, VS Code for coding, and Zoom for video calls). This causes confusion, lost notes, distraction, and missed deadlines.

3. The Smart AI Advantage

Unlike traditional tools, our system has built-in Machine Learning (Random Forest) that proactively predicts whether a task will be delayed before the deadline hits. It also integrates Google Gemini AI to turn meeting notes into assigned tasks with one click.

Slide 3: Objectives of the Project

01
Build an All-in-One Team Workspace

Replace 5 separate applications with one unified dashboard combining Kanban tasks, team chat, collaborative documents, code editor, and video meetings.

Slide 4: Problem Statement vs. Proposed Solution

Existing Problems (Current Tools)

  • App Overload & High Costs: Switching between Slack, Jira, Zoom, and Docs wastes 20-30% of daily time.
  • Late Deadline Warnings: Conventional tools notify managers only after a task is already overdue.
  • Lost Meeting Notes: Important action items from calls get lost without being recorded as tasks.
  • Data Privacy Risks: Using multiple separate tools increases the danger of accidental file leaks.

Our Proposed Solution (This Project)

  • Unified All-in-One Hub: Tasks, Chat, Docs, Code Editor, and Video Calls all under one login.
  • Proactive Machine Learning: Color-coded badges (Green, Yellow, Red) alert managers early to prevent delays.
  • 1-Click AI Task Generation: Gemini AI reads meeting notes and automatically creates assigned Kanban tasks.
  • Hard Database Isolation: JWT authentication and SQL organization scoping guarantee 100% data privacy.

Slide 5: System Design & Architecture

Tier 1: Frontend User Interface (React 18 + Tailwind CSS)

Kanban Task Board • Real-Time Chat • Collaborative Docs • Monaco Code Studio • WebRTC Video Meet

↕ HTTPS REST API (JWT Security) & Live WebSockets (Socket.IO + CRDT Document Sync)
Tier 2: Backend Server & API Gateway (Node.js & Express - Port 5000)

User Login & Tokens • Team Role Permissions • CRDT Sync Engine • Video Call Signaling • Audit Logging

↙ PostgreSQL Database Connection (SQL) ↘ Fast HTTP Prediction Requests (REST)
Database: PostgreSQL 18 (Port 5432)

• 21 Relational tables for users, tasks, docs, and chat.
• Strict tenant privacy: Users only see their team's data.
• Full audit history of task status changes and revisions.

AI / ML Tier: Python FastAPI (Port 8000)

• Random Forest ML model with 89.03% delay prediction accuracy.
• Decoupled service: Heavy AI never slows down the website.
• Google Gemini AI integration for meeting summaries.
